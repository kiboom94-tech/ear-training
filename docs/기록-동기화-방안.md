# 기록·코스 진도를 휴대폰과 PC에서 같이 쓰기

## 지금 쓸 수 있는 방법: 학생 코드 + 구글 시트 (구현됨)

같은 **학생 코드**를 넣은 기기들은 기록·약점 지도·코스 진도·틀린 문제가 합쳐지고, 선생님 구글 시트의 **'학생 기록'** 시트에 학생별 요약 한 줄이 올라갑니다.

### 선생님이 한 번만 할 일 (10분)
1. 구글 드라이브에서 새 구글 시트를 만듭니다. 이름은 자유 (예: `청음 트레이너 기록`).
2. 위 메뉴 **[확장 프로그램] → [Apps Script]** 를 누릅니다.
3. 열린 화면의 코드를 모두 지우고, 저장소의 `tools/sync-apps-script.gs` 내용을 전부 복사해 붙여 넣은 뒤 💾 저장합니다.
4. 오른쪽 위 **[배포] → [새 배포]** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - [배포] → 구글 계정 권한 허용 (처음 한 번 "확인되지 않은 앱" 경고가 나오면 [고급] → [이동])
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 학생에게 보내는 링크
아래처럼 앱 주소 뒤에 `?sync=웹앱URL&code=학생코드` 를 붙여 보내면, 학생이 누르기만 해도 설정이 끝납니다.

```
https://(앱 주소)/index.html?sync=https://script.google.com/macros/s/…/exec&code=YCD-01
```

또는 학생이 앱의 **기록 (Stats) 탭 → 기기 연결 · 선생님 시트** 에서 학생 코드와 주소를 직접 넣고 [저장하고 동기화]를 누릅니다. 휴대폰과 PC에 **같은 코드**를 넣으면 기록이 합쳐집니다.

### 언제 동기화되나
- 앱을 열 때, 문제를 풀고 20초가 지났을 때, 앱을 닫거나 다른 앱으로 넘어갈 때, [지금 동기화]를 누를 때.
- 인터넷이 안 되면 이 기기에 계속 쌓였다가 다음에 합쳐집니다. 기록이 사라지지 않습니다.

### 시트에서 보이는 것 ('학생 기록' 시트)
학생 코드 · 이름 · 마지막 동기화 · 오늘 푼 문제 · 연속 연습일 · 최근 7일 문제 수와 정답률 · 코스 통과 단계 수 · 영역별 정답률(푼 수) · 약점(배우는 중인 항목 5개).
`data` 시트는 앱이 쓰는 원본이니 지우거나 고치지 마세요.

### 알아 둘 점
- 학생 코드를 아는 사람은 그 학생 기록을 읽고 덮어쓸 수 있습니다. 이름 대신 짧은 코드(예: `YCD-01`)를 쓰세요.
- 두 기기에서 **동시에** 몇 초 차이로 동기화하면 그 사이 푼 몇 문제가 한쪽에서 빠질 수 있습니다. 보통 사용에서는 문제없습니다.
- 합치는 규칙: 맞힘·시도 같은 숫자는 "시트 값 + 이 기기에서 늘어난 만큼"으로 더하고, 그 밖의 값은 이 기기에서 바뀐 쪽을 씁니다. 코스는 한 기기에서라도 통과하면 통과입니다.
- 학생이 100명을 넘거나 선생님용 화면(학생 목록·숙제)이 필요해지면 아래 ③ Firebase 등으로 옮기는 것을 검토하세요.

## 방법 비교

| 방법 | 설명 | 장점 | 단점 | 작업량 |
|---|---|---|---|---|
| **① 내보내기 / 가져오기 파일** | 기록 화면에 "기록 내보내기(JSON 파일)" · "가져오기" 버튼. 파일을 카톡·메일로 옮김 | 서버 없음, 지금 구조 그대로, 개인정보 걱정 없음 | 매번 손으로 옮겨야 함. 두 기기에서 번갈아 쓰면 합치기가 애매함 | 작음 (반나절) |
| **② 학생 코드 + 구글 시트 (Apps Script)** | 학생마다 짧은 코드(예 `YCD-0123`)를 입력. 문제를 풀 때마다 결과 한 줄을 구글 시트에 보내고, 시작할 때 시트에서 불러옴. 학원관리 시트와 같은 파일에 둘 수도 있음 | 서버 비용 0원, 선생님이 시트에서 바로 전체 학생 기록을 봄(숙제 확인 가능), 학원관리 시트와 연동 쉬움 | Apps Script 배포가 필요(한 번), 시트는 동시 쓰기에 약해 학생이 많아지면 느려질 수 있음(100명 이내는 무난), 학생 코드를 아는 사람은 누구나 볼 수 있어 비밀번호가 필요하면 추가 작업 | 중간 (2~3일) |
| **③ Firebase / Supabase 같은 무료 DB** | 구글 로그인(또는 코드 로그인) 뒤 기록을 클라우드 DB에 저장. 기기 어디서든 자동 동기화 | 자동 동기화가 가장 매끄럽고, 오프라인에서도 쌓였다가 나중에 올라감, 선생님 화면(학생 목록·진도) 만들기 좋음 | 계정·프로젝트 관리가 필요, 무료 한도(Firebase Spark: 하루 읽기 5만·쓰기 2만 정도)는 넉넉하지만 넘으면 유료, 정적 사이트에 SDK 추가 | 중간~큼 (3~5일) |
| **④ GitHub 로그인 + 저장소 파일** | GitHub Pages와 같은 계정으로 학생별 JSON 파일을 저장소에 커밋 | 추가 서비스 없음 | 학생이 GitHub 계정을 만들어야 해서 현실적으로 어려움 | 추천하지 않음 |

## 추천 순서

1. **지금 당장**: ① 내보내기/가져오기 — 작업이 작고, 기기 이동이 가끔인 학생에게는 충분합니다.
2. **학원 운영에 쓰려면**: ② 학생 코드 + 구글 시트 — 선생님이 이미 구글 시트로 학원을 관리하고 있으니 "숙제·기록 공유"(나중에 할 것)와 한 번에 해결됩니다. 설계 요점:
   - 시트에 `기록` 탭: `시각, 학생코드, 모드, 항목, 정답여부, 점수, 난이도` 한 줄씩 추가(append).
   - 시트에 `코스` 탭: 학생코드별 코스 진도 JSON 한 칸.
   - 앱은 시작할 때 시트에서 내 기록을 내려받아 localStorage와 **합치고**(같은 시각 기록은 중복 제거), 문제를 풀 때마다 한 줄 보냄. 인터넷이 안 되면 localStorage에만 쌓았다가 다음에 보냄.
   - localStorage 키 이름은 그대로 두고, "동기화 켜기"를 설정에서 선택하게 하면 기존 기록이 사라지지 않습니다.
3. **학생이 많아지거나 선생님 화면이 필요해지면**: ③ Firebase 등으로 옮김. ②에서 만든 "한 줄 기록" 구조를 그대로 쓰면 이사가 쉽습니다.

## 어떤 방법이든 공통으로 필요한 것
- 두 기기 기록을 **합치는 규칙**: 문제별 기록에 시각(ms)을 붙여 같은 기록은 한 번만 세기. 코스 진도는 "더 많이 통과한 쪽"을 우선.
- **학생 식별**: 이름 대신 짧은 코드 사용(개인정보 최소화).
- 기록 화면에 "마지막 동기화 시각"과 "지금 동기화" 버튼.
